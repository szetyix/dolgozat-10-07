# Feladat 0311

Angular alkalmazás az általános programozási feladatgyűjtemény 0311. feladatához.

## Fejlesztői szerver indítása

```bash
npm start
```

Ezután nyisd meg a [http://localhost:4200](http://localhost:4200) címet. A forrásfájlok módosításakor az alkalmazás automatikusan újratöltődik.

## Build

```bash
npm run build
```

A lefordított alkalmazás a `dist/` mappába kerül.

## Tesztek

```bash
npm test
```
